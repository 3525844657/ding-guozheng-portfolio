# Ding Guozheng · Portfolio

基于 React、Vite、Tailwind CSS 和 Framer Motion 构建的暗黑风格个人作品集。

## 在线地址

- 网站：https://ding-guozheng-portfolio.vercel.app
- 仓库：https://github.com/3525844657/ding-guozheng-portfolio

## 本地运行

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
npm run preview
```

## 当前素材

| 用途 | 文件 |
| --- | --- |
| 航空安全 Agent 截图 | `public/images/aero-*.jpg` |
| 行业情报工作流截图 | `public/images/intel-*.jpg` |
| 简历下载 | `public/resume.pdf` |
| 首屏视频封面 | `public/images/hero-poster.svg` |

首屏视频仍使用占位路径 `public/videos/bg.mp4`。替换为 8–15 秒、无声、暗色科技感 MP4 即可，建议小于 8 MB。
